# **TELA DE LOGIN ANIMADA**

 **Tela de Login e Cadastro com Efeito Neon**

Projeto front-end de uma interface de login e cadastro interativa. O foco principal foi trabalhar com animações e transformações tridimensionais em CSS puro, acompanhado de uma estética dark com iluminação neon.

## **O que foi implementado:**

**-Transição em 3D:** Alternância entre a tela de login e a de registro usando rotação no eixo Y (transform: rotateY com preserve-3d).
<br> **- Animações em CSS:** Borda circular animada com gradiente cônico e sombreamento contínuo.
<br> **- Responsividade:** Ajuste de proporções e tipografia para manter a usabilidade tanto em dispositivos móveis quanto em telas maiores.
<br> **- JavaScript Vanilla:** Controle simples de classes para disparar a troca de formulários sem recarregar a página.

## **Tecnologias:**

- HTML5
- CSS3
- JavaScript (Vanilla)
